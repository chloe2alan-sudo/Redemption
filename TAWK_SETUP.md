# Tawk.to live chat

The site is prepared for the Tawk.to widget. In Tawk.to, select your property and open Administration -> Chat Widget. Copy the Property ID and Widget ID, then replace `YOUR_PROPERTY_ID/YOUR_WIDGET_ID` in `public/index.html`, `public/blog.html`, and `public/article.html`. Rebuild with `docker compose up -d --build`.

Tawk.to official setup: https://help.tawk.to/article/adding-a-widget-to-your-website
